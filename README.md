# SofaRush UK — Premium UK Sofa Store

A responsive sofa catalogue concept for a UK-based furniture brand. The updated visual direction is distinct from the earlier green-and-ivory concept: editorial ink/oxblood, warm paper, copper accents, sharper geometry, and a high-contrast cinematic hero.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before launch
- Replace the demo WhatsApp number `447000000000` with the business number.
- Replace `yourpageusername` with the real Facebook Page username.
- Confirm all product names, prices, stock, measurements, delivery terms, quality descriptions, and images.
- Product colour previews currently switch between sample reference images. Add accurate, separately photographed images for each real fabric colour.
- Review and replace sample reviews; publish a privacy policy that accurately reflects actual data handling and UK GDPR obligations.
- Add a real domain in the canonical URL and configure sitemap/robots.txt and Search Console after deployment.

Product prices and reviews in this demo are illustrative and must be verified before public use.
